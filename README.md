# Draft-Collective

Collect my manga draft and inspiration.

一個給手機用的小型漫畫手稿 App（PWA）。打開只有兩個按鈕：

| 圖示 | 功能 |
| --- | --- |
| ◉ 紅色圓點 | 拍照記錄隨筆畫作 |
| ▦ 四格方塊 | 觀看、編輯隨筆畫作 |

## 編輯工具（檢視畫面下方）

| 圖示 | 功能 |
| --- | --- |
| ⌐ 兩個直角 | 剪裁（拖曳四角 / 拖曳框移動，↻ 旋轉 90°） |
| ▱ 橡皮擦 | 單指擦掉不要的線條，雙指縮放移動；滑桿調整大小，↶ 復原（線稿擦成透明，照片擦成紙張顏色） |
| △ 空心三角 | 提取去背線稿（滑桿調整線條濃度，◐ 切換預覽背景；存成新的透明 PNG，原圖保留） |
| ✡ 六角星 | 風格：素描／蠟筆／浮雕，滑桿調整強度（存成新的一張，原圖保留） |
| ≡ 三條線 | 靈感筆記（自動儲存；有筆記時出現紅點） |
| ⇧ 箭頭 | 分享 / 存到手機 |
| 🗑 垃圾桶 | 刪除（會再確認一次） |

其他操作：

- 檢視時左右滑動切換畫作，雙擊或雙指放大
- 畫冊右上角 ＋ 可以從手機相簿匯入舊圖
- 畫冊縮圖左下紅點 = 有筆記，右下黑三角 = 線稿，右下紅色六角星 = 風格
- 手機的返回鍵 / 返回手勢可以正常使用

所有資料都只存在手機瀏覽器本地（IndexedDB），不會上傳；可離線使用。

## 線稿提取原理

使用自適應閾值：每個像素跟周圍區域的平均亮度比較，比周圍暗的部分視為線條，
其他（紙張、陰影、光線不均）變透明，輸出黑色線條 + 透明背景的 PNG。
拍照時盡量讓紙張平整、光線均勻，效果最好。

## 放到手機上使用

相機與安裝到主畫面需要 HTTPS，最簡單是用 GitHub Pages：

1. 把這個分支合併到 `main`
2. GitHub 倉庫 → **Settings → Pages → Source** 選 **GitHub Actions**
3. 推送後 `.github/workflows/pages.yml` 會自動部署，網址類似
   `https://<帳號>.github.io/Draft-Collective/`
4. 用手機打開網址：
   - iPhone（Safari）：分享 → 加入主畫面
   - Android（Chrome）：選單 → 安裝應用程式 / 加到主畫面

## 本地開發

不需要建置，任何靜態伺服器即可：

```sh
python3 -m http.server 8000
# 打開 http://localhost:8000
```

## 檔案

```
index.html            畫面結構與幾何圖示
style.css             樣式
app.js                功能邏輯（拍照、畫冊、檢視、剪裁、線稿、筆記）
db.js                 IndexedDB 儲存
filters.js            風格濾鏡（素描、蠟筆、浮雕）
sw.js                 離線快取
manifest.webmanifest  PWA 設定
icons/                App 圖示
```
